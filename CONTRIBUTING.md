# Как внести вклад в SlidgeMAX

Прежде всего, спасибо за интерес к SlidgeMAX! Это личный проект, которым я делюсь с сообществом, и любой вклад искренне приветствуется.

## Способы помочь

- **Поддерживайте других пользователей** — отвечайте на вопросы в issues, делитесь опытом настройки или помогайте решать проблемы.
- **Присылайте pull requests** — код для нужных вам функций очень приветствуется.
- **Улучшайте документацию** — понятные доки, исправления опечаток и примеры использования так же ценны, как и код.
- **Поддержите проект финансово** — это помогает покрывать расходы на разработку и LLM.
- **Сообщайте об ошибках** — хорошо описанные баг-репорты помогают сделать проект стабильнее.

## Важно: зависимость от PyMax

SlidgeMAX сильно зависит от [PyMax](https://github.com/MaxApiTeam/PyMax). Отсутствие некоторых функций может быть связано с ограничениями самого PyMax.

**Прежде чем открывать запрос на функцию или PR в этом репозитории, подумайте, не лучше ли внести изменение в PyMax.** Если PyMax не предоставляет нужные данные или методы, правильное место для их добавления — репозиторий PyMax.

## Pull Requests

1. Сделайте форк репозитория и создайте отдельную ветку.
2. Установите зависимости для разработки:
   ```bash
   uv sync --dev
   ```
3. Внесите изменения. Пожалуйста, следуйте существующему стилю кода.
4. Добавьте или обновите тесты, если применимо. Запустите тесты:
   ```bash
   uv run pytest
   ```
5. Обновите документацию (включая README или этот файл), если это необходимо.
6. Откройте pull request с чётким описанием изменения и того, зачем оно нужно.

## Ожидания

Это **хобби-проект**, а не коммерческий продукт. Гарантированного времени ответа нет, и запросы на функции могут остаться нереализованными. Автор разрабатывает проект в первую очередь для себя и делится им, потому что это может быть полезно другим.

Пожалуйста, будьте терпеливы и уважительны. Вклад — это подарок, а не обязанность.

## Лицензия

Внося вклад, вы соглашаетесь с тем, что ваши изменения будут лицензированы под той же [лицензией Apache-2.0](LICENSE), что и проект.
